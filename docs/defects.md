## Дефекты:
1. **В поле имени можно ввести xss-инъекцию**
 - приоритет: critical
 - окружение: браузер Google Chrome (версия: 157.0.8103.79), ОС Windows 11 Pro
 - предусловие: пользователь находится на странице бронирования, все поля, кроме "Имя" заполнены валидными данными
 - шаги:
	1. Ввести в поле "Имя" текст <img src=xxx onerror=alert('XSS')>
	2. Нажать "Забронировать"
 - ожидаемый результат: введенный текст экранируется, имя выводится как текст, скрипт не срабатывает
 - фактический результат: появляется алерт (скрипт выполнился), экранирования нет


 
2. **Нет ограничений по длительности встречи**
 - приоритет: high
 - окружение: браузер Google Chrome (версия: 157.0.8103.79), ОС Windows 11 Pro
 - предусловие: пользователь находится на странице бронирования
 - шаги:
	1. Выбрать время в поле "Начало"
	2. В поле "Окончание" выбрать время меньше, чем через 30 минут, или больше, чем через 4 часа
	3. Нажать "Забронировать"
 - ожидаемый результат: по требованиям "Время окончания позже начала, длительность от 30 минут до 4 часов.", должна появляться ошибка
 - фактический результат: ошибки нет, на данный момент в коде такая проверка отсутствует


 
3. Доступен выбор прошедшего времени
 - приоритет: medium
 - окружение: браузер Google Chrome (версия: 157.0.8103.79), ОС Windows 11 Pro
 - предусловие: пользователь находится на странице бронирования, все поля, кроме начала и окончания заполнены валидными данными, дата - текущий день
 - шаги:
	1. Выбрать в поле "Начало" время, которое уже прошло (в соответствии с текущим временем), например 10:00, если текущее время позже (например, 11:00)
	2. Выбрать в поле "Окончание" время, позже начала, но раньше текущего времени (например, 10:30)
	3. Нажать "Забронировать"
 - ожидаемый результат: ошибка "Время не может быть в прошлом"
 - фактический результат: успешное бронирование


 
4. **Нет плюрализации для слова "участник" в тексте ошибки валидации**
 - приоритет: medium
 - окружение: браузер Google Chrome (версия: 157.0.8103.79), ОС Windows 11 Pro
 - предусловие: пользователь находится на странице бронирования, все поля, кроме "участник" заполнены валидными данными
 - шаги:
	1. В поле "Переговорная" выбрать вариант "Средняя"
	2. В поле "Участник" ввести число 11
	3. Нажать "Забронировать"
 - ожидаемый результат: текст ошибки "В комнате максимум 10 участникОВ."
 - фактический результат: текст ошибки "В комнате максимум 10 участникА."


 
5. **В поле "Участники" доступен ввод недопустимых символов**
 - приоритет: medium
 - окружение: браузер Google Chrome (версия: 157.0.8103.79), ОС Windows 11 Pro
 - предусловие: пользователь находится на странице бронирования, все поля, кроме "участник" заполнены валидными данными
 - шаги:
	1. Ввести в поле "Участники" символы "-" (минус), "." (точку), "e" (английская раскладка)
	2. Очистить поле и ввести "1e1"
 - ожидаемый результат: ошибка, ввод невалидный. поле должно разрешать только ввод цифр
 - фактический результат: математически "1e1" = 10, потому этот ввод валиден при выборе переговорной "Средняя" или "Большая"
